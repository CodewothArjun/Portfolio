# Arjun Mijar — Portfolio

A modern personal portfolio built with Next.js, Tailwind CSS, and GSAP to showcase my work, projects, technical skills, and professional journey.

This portfolio is designed to present my background as a developer in a clean, engaging, and interactive way. It includes a strong hero section, project highlights, professional profile details, and an interactive chat widget that answers common questions about my experience and work.

## ✨ Highlights

- Professional landing page and personal branding
- Responsive design for desktop and mobile screens
- Animated sections using GSAP
- Project showcase with technology tags
- Chat widget for quick portfolio interaction
- Dark-themed developer aesthetic
- Built with modern frontend technologies

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- GSAP

## 🚀 Run Locally

```bash
npm install
npm run dev
```

Then open:

```bash
http://localhost:3000
```

## 📁 Project Structure

- `src/app/page.tsx` — main portfolio page
- `src/components/TerminalIntro.tsx` — animated terminal-style intro
- `src/components/Reveal.tsx` — scroll reveal animation wrapper
- `src/components/ChatWidget.tsx` — interactive Q&A widget
- `src/components/ThemeToggle.tsx` — theme switcher
- `src/app/globals.css` — global styling and theme variables
